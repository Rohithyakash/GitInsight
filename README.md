# GitInsight

## Overview
GitInsight is an AI-powered web application that analyzes GitHub repositories and provides intelligent insights about the project. It helps developers understand repository structure, code quality, technologies used, and project information quickly.

## Features
- Analyze public GitHub repositories
- Generate AI-powered project summaries
- Display repository information
- Show programming languages and technologies
- User-friendly interface

## Tech Stack
- Google AI Studio (Gemini)
- GitHub API
- HTML
- CSS
- JavaScript

## How It Works
1. Enter a GitHub repository URL.
2. GitInsight fetches repository information using the GitHub API.
3. Gemini AI analyzes the repository.
4. The application displays a detailed summary and useful insights.

## Future Improvements
- Code quality scoring
- Issue and pull request analysis
- Repository comparison
- Downloadable analysis reports
